# MONO. — test-babu-1919 (Vite, no backend)

Black-and-white customizable toothpaste storefront. Vite + React static. No backend — cart in localStorage only.

## Run
```bash
npm install
npm run dev
npm run build
```

## Deploy to test-babu-1919.vercel.app
1. Vercel → Add New Project → Import `SVJSimplify/test-babu-1919`.
2. Framework: Vite. Build: `npm run build`. Output: `dist`.
3. Project name: `test-babu-1919` → URL `test-babu-1919.vercel.app` (if taken, Vercel assigns suffix).
